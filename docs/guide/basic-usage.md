# 基本的な使い方

[ドキュメントトップ](../index.md) | [利用規約](../ja/terms.md) | [プライバシーポリシー](../ja/privacy.md)

## 初回設定

[セットアップウィザード](../ja/setup-wizard.md)で写真フォルダなどを設定します。設定後はサイドバーの監視状態を確認し、新しい写真が取り込まれることを確認してください。

## 写真の管理

- [ギャラリー](../ja/gallery-guide.md)で一覧と写真詳細を表示します。
- [ユーザー・ワールド検索](../ja/person-search-guide.md)で撮影時の情報から写真を探します。
- [ローカルアルバム](../ja/albums-guide.md)と[お気に入り](../ja/favorites-guide.md)で写真を整理します。
- [レタッチ・EXIFスタジオ](../ja/retouch-guide.md)で画像を調整し、カメラ情報を添えて書き出します。
- [JXL圧縮](../ja/jxl-compression.md)で容量を節約できます。重要な写真は別の場所にもバックアップしてください。

## VRChat連携と設定

[VRChat連携](../ja/vrchat-integration.md)で撮影情報の取得条件を、[設定ガイド](../ja/settings-guide.md)で表示や通知を確認できます。外部通信の詳細はプライバシーポリシーを参照してください。

このガイドはVSA v0.9.0の現行ローカル機能と操作を基準にしています。アカウント・クラウド保存・X投稿・イベント撮影は一般提供の準備中で、通常設定では表示されません。
