# はじめに（初回セットアップ）

初回設定の手順は[セットアップウィザード](../ja/setup-wizard.md)にまとめています。

1. [インストール](../installation.md)を確認してVSAを起動します。
2. ウィザードで言語・テーマ・写真フォルダなどを設定します。
3. [ギャラリー操作ガイド](../ja/gallery-guide.md)で取り込まれた写真を確認します。

設定後の操作は[基本操作ガイド](basic-usage.md)、[ドキュメントトップ](../index.md)から確認できます。
