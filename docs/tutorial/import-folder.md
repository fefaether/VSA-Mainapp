# フォルダのインポート

このガイドでは、VRChatの写真フォルダをVSAに追加して管理する方法を説明します。

## フォルダの追加

### 手順

1. サイドバーの「ギャラリー」を開きます。
2. 画面上部の「インポート」タブを開きます。
3. 「フォルダ追加」をクリックし、ファイルダイアログで親フォルダを選択します。
4. 直下にサブフォルダがある場合は、写真を取り込むサブフォルダだけにチェックを入れ、「選択したフォルダを取り込む」をクリックします。
5. 直下にサブフォルダがない場合は、選択した親フォルダがそのまま取り込み対象になります。

フォルダ追加後はスキャンが自動的に開始されます。フォルダの追加に失敗した場合は、アクセス権、パスの存在、既に登録済みでないかを確認してください。

### VRChatのデフォルトフォルダ

VRChatの写真は通常、以下の場所に保存されています:

```
%USERPROFILE%\Pictures\VRChat
```

例: `C:\Users\ユーザー名\Pictures\VRChat`

## フォルダの管理

### フォルダ一覧

追加したフォルダは一覧で表示されます。各フォルダには以下の情報が表示されます:

- フォルダパス
- サブフォルダ一覧と有効/無効状態
- 処理中・エラーなどの取り込み状況

### フォルダの有効/無効

ルートフォルダとサブフォルダのチェックボックスで、取り込み対象を切り替えます。ルートを無効にすると配下のサブフォルダも無効になり、再度有効にすると直前の選択状態が復元されます。

### フォルダの削除

不要なフォルダを削除するには:

1. 削除したいフォルダを選択
2. 「選択したフォルダ削除」または個別の削除ボタンをクリック
3. 確認ダイアログで実行します

**注意**: フォルダの削除は監視対象からの登録解除と抽出結果の削除です。元の画像ファイルは削除されません。VRChatの撮影フォルダとして管理されている親フォルダは削除・無効化できませんが、配下のサブフォルダは切り替えられます。

## 新しいサブフォルダの自動取り込み

インポート画面の「新規サブフォルダを自動で取り込む」を有効にすると、登録済みフォルダの直下に新しく作られたサブフォルダを、VSAの起動中に検出して取り込みます。月別フォルダなどが増える運用に向いています。

1. 取り込み元になる親フォルダを登録し、有効にします。
2. インポート画面の「新規サブフォルダを自動で取り込む」をオンにします。
3. VSAの起動中、新しく作られた直下のサブフォルダが自動的に追加されます。

この設定がオフでも、インポート画面を開いたときには新規サブフォルダの検出が行われます。個々の写真を一定間隔で汎用スキャンする設定ではありません。

## 取り込み状況の確認・停止

フォルダ追加後の処理は自動で開始され、インポート画面のステータスバーと画面下部のステータスフッターに進捗が表示されます。処理中は「全ての処理を停止」で実行中の取り込みを停止できます。

クラウド連携が表示される環境では、フォルダごとのVRC+写真のアップロード除外設定と除外履歴も同じ画面で確認できます。利用可否は段階的に公開されます。

## ヒント

### 複数フォルダの管理

- 年別や月別にフォルダを分けている場合、すべて追加できます
- フォルダ名で内容を識別しやすくしましょう

### パフォーマンス

- 大量の写真があるフォルダの初回スキャンには時間がかかることがあります
- 追加後の処理は新しいファイルを中心に行うため、初回より短時間で完了します

### トラブルシューティング

**フォルダが追加できない場合:**
- フォルダへのアクセス権限を確認
- パスに特殊文字が含まれていないか確認

**写真が検出されない場合:**
- 対応形式: PNG, JPG, JPEG, GIF, BMP, WebP
- 取り込み対象として有効になっているルート/サブフォルダか確認
- サブフォルダは一覧で個別に有効化できます
