## イベントを開く

イベント機能が利用できる場合は、サイドバーの**アルバム**を開き、**イベント**タブを選びます。イベントアルバムを使うにはアカウントへのログインが必要です。

## イベントを作成または追加する

- 主催する場合は**イベントアルバムを作成**からイベント名と開催日を入力し、**イベントを作成**を選びます。
- 招待を受けた場合は、招待URLを入力するか、イベントIDと招待トークンを入力します。招待パスワードが設定されている場合は入力し、**イベントに参加**を選びます。
- **参加中のイベント**からイベントを選ぶと、詳細と写真を表示できます。

## この端末の撮影をイベントに追加する

1. イベント詳細で写真受付が**ON**になっていることを確認します。
2. **このイベントに撮影する**を選び、確認画面で**撮影を開始**します。
3. 以後、この端末で撮影した新しい写真が選択したイベントに自動で送られます。
4. 終了するときは**この端末の撮影を停止**を選びます。停止前に送信待ちになった写真は、写真受付中であれば送られることがあります。

写真受付を開始・停止できるのは主催者です。これはイベント全体の設定で、端末ごとの撮影開始・停止とは別です。受付を停止しても、すでに保存された写真は残ります。
