# レタッチ機能ガイド

## 開き方

サイドバーの**レタッチ（アルファ版）**、またはギャラリーの写真詳細からレタッチ画面を開きます。

![レタッチ画面](../assets/screenshots/retouch-auto-exposure.webp)

---

レタッチは、元ファイルを上書きせずに調整結果を別ファイルへ書き出す機能です。調整状態は自動保存されないため、残したい結果は**書き出し**で保存してください。

## 画面構成

- 中央: プレビュー。ズーム、ウィンドウに合わせる、左右90度回転ができます。
- 下部: **最近**と**お気に入り**を切り替えられるフィルムストリップ。最近の写真は末尾まで移動すると追加読み込みされます。
- 右側: 調整パネル。**スタンダード／詳細モード／クロップ**の3タブです。
- タイトルバー: **元に戻す／やり直す／リセット／書き出し**。

## 写真の比較

フィルムストリップで2枚以上を選ぶと比較画面に切り替わります（最大4枚）。1枚だけ選んでいる場合は、タイトルバーの**比較**を押すと隣の写真を加えて開始します。

比較画面では各写真の**Before／After**を切り替えられます。2枚を比較するときは左右／上下の配置を選べます。「適用対象」では比較中の全写真またはフォーカス中の写真を選びます。「戻る」で比較画面を終了します。編集後は、編集内容を保持するか破棄するかを選べます。

## スタンダード

### 自動露光

**自動露光を適用**を押すと、プレビュー画像を解析して露光補正、黒レベル、Lightness、ハイライト圧縮、コントラストを調整します。クリップ率を先に指定できます。現在は精度が低く、白飛びが発生する場合があります。

### 手動調整

- **露光補正**: EV単位の明るさ補正
- **黒レベル／Lightness**: 暗部と全体の明るさ
- **ハイライト圧縮**: 明部の抑制
- **明度／コントラスト／彩度**
- **色温度**: 寒色・暖色（表示値は -100～+100）
- **ハイライト／シャドウ**

各項目はスライダーまたは数値欄で調整できます。行末のリセットで項目ごとに初期値へ戻せます。

### トーンカーブ

RGB、R、G、Bのチャンネルを選び、曲線をクリックして制御点を追加します。制御点はドラッグで移動し、右クリックで削除できます。

## 詳細モード

詳細モードでは、次の項目をアコーディオンから調整できます。

- **HSL調整**: 赤、オレンジ、黄、緑、アクア、青、紫、マゼンタごとの色相・彩度・輝度
- **シャープネス**
- **ノイズ低減**: 輝度／カラー
- **ビネット**: 強度、サイズ、フェザー
- **カラーグレーディング**: シャドウ、ミッドトーン、ハイライト
- **モノクロ**: 有効化とRGB比率

### フィルムルック

詳細モードの**フィルムルック**からルックと適用量を選び、粒子の強さ・密度・サイズを調整できます。**.cubeを読み込む**から3D LUTを追加できます。画面画像に現在の操作が表示されていない場合があります。

## クロップと回転

1. **クロップ**タブで**クロップ範囲を指定する**を選びます。
2. プレビュー上の範囲をドラッグして移動・サイズ変更します。
3. 必要なら比率を**フリー／元画像／1:1／4:3／3:2／16:9／9:16／4:5**から選びます。
4. **クロップを解除**で範囲を取り消します。

範囲はドラッグ操作時に確定され、別の**適用**ボタンはありません。選択範囲は書き出し結果に反映されます。回転はプレビュー下部の左右90度ボタンから行い、回転状態も履歴に含まれます。

## 書き出し

タイトルバーの**書き出し**を押し、形式とプリセットを選びます。

- 形式: **JPEG** または **PNG**
- **オリジナル**: 元の解像度で出力
- **X投稿向け**: 1920×1080px以内に収める、ローカル画像書き出し用のサイズプリセット
- **VRChat website向け**: 長辺の最大ピクセル数を指定して出力（640～8192px）

保存先とファイル名を確認すると、別ファイルとして保存され、保存後に出力先が開きます。書き出し中はダイアログを閉じられません。

## EXIFスタジオ（カメラ情報フレーム）

サイドバーの**EXIFスタジオ（ベータ）**を開くと、写真の下部にカメラ情報を配置するフレームを作成できます。最近／お気に入りのフィルムストリップとプレビューを使い、設定は次のように調整できます。

- EXIFプリセットの保存と、自分で保存したプリセットの適用・削除・並べ替え
- 表示モード（デフォルト：左右分割／シンプル：1列）、文字配置、フォント、色テーマ
- ボーダー幅、下部バー高さ、フォントサイズ
- カメラ種別、F値、焦点距離、ワールド名、撮影者名の表示
- 透かしの有無、位置、文字、サイズ、不透明度

EXIFスタジオの**書き出し**にもJPEG/PNGと書き出しプリセットがあります。

設定欄のテンプレートから、**自動／横長／正方形／縦長**を選べます。**自動**は写真の縦横比に合わせてレイアウトを調整します。テンプレートは表示モード、文字配置、枠幅、下部バーの高さを設定し、カメラ情報や透かしなど他の項目は現在の設定を引き継ぎます。必要に応じて、テンプレート適用後に各項目を調整し、自分の設定をEXIFプリセットとして保存できます。

## 注意事項

- レタッチの調整値は自動保存されません。必要な写真は書き出してください。
- 元の写真ファイルは直接変更されません。
