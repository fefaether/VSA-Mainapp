## Open Events

When event features are available, open **Albums** from the sidebar and choose the **Events** tab. You must be signed in to use event albums.

## Create or join an event

- To host an event, choose **Create an event album**, enter the event name and date, then choose **Create event**.
- To join an invitation, enter its URL, or enter the event ID and invitation token. Enter the invitation password if one is set, then choose **Join event**.
- Select an event under **Your events** to view its details and photos.

## Add this device's captures to an event

1. In the event details, check that **Photo reception** is **ON**.
2. Choose **Capture to this event**, then confirm with **Start capture**.
3. New photos captured on this device are automatically submitted to the selected event.
4. To finish, choose **Stop capture on this device**. Photos already queued before stopping may still be sent while photo reception is open.

Only the host can open or close photo reception. This setting applies to the whole event and is separate from starting or stopping capture on this device. Closing reception does not remove photos that have already been saved.
