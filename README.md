## VSAって何？

Virtual Snap Archive（VSA）は、写真を整理し、撮影時の文脈やカメラ情報をあとから確認できるようにするアプリです。

- 写真がフォルダに散乱して整理できない
- どこで撮ったか、誰と撮ったか思い出せない
- 大量のスクショでストレージがパンパン

VSAはローカルでの写真管理を基本にしています。アカウント、クラウド保存、X投稿、イベント撮影は一般提供の準備中で、通常設定では表示されません。

## インストール方法

### システム要件

- **OS**: Windows 10/11 (64bit推奨)
- **メモリ**: 4GB以上推奨（2GB最小）
- **ディスク**: 500MB以上の空き容量（圧縮機能使用時は別途容量必要）
- **画面**: 1920×1080以上推奨

### インストール手順

1. [**ダウンロードページ**](https://github.com/fefaether/VSA-Mainapp/releases/)へ移動
2. 最新版の`VSA-Setup-vX.X.X.exe`をダウンロード
3. ダウンロードしたファイルを実行
4. 画面の指示に従ってインストール
5. デスクトップのアイコンからVSAを起動！

## できること

### VSA - 写真管理アプリ

| 機能 | 説明 |
|------|------|
| **ギャラリー表示** | 撮った写真を一覧で見やすく表示 |

## 使い方

### はじめての設定

初回起動時のウィザードで言語・テーマ・写真フォルダなどを設定します。[セットアップウィザード](./docs/ja/setup-wizard.md)を順に進めてください。

設定後はサイドバーの監視状態を確認し、「ギャラリー」で取り込まれた写真を表示できます。フォルダを変更する場合は「ゲーム関連設定 > 画面設定」を開きます。

### よく使う操作

| やりたいこと | 方法 |
|--------------|------|
| 写真を大きく見る | サムネイルをクリック |
| お気に入り登録 | お気に入りボタンをクリック |
| 写真を圧縮 | サイドバーのJXL圧縮画面、または設定の自動アーカイブを利用 |

## よくある質問

### 写真が表示されない

1. フォルダが正しく設定されているか確認
2. サイドバーにフォルダ監視中の状態が表示されるか確認
3. アプリを再起動してみる
4. VSAが読み取り権限を持っているか確認

### 容量を節約したい

JXL圧縮画面で写真を選択して圧縮するか、設定 > システムの「古い写真の自動アーカイブ」を有効にします。圧縮による削減量は写真によって異なります。

### VRChatプレイ中に動作が重くなる？

JXL処理画面ではVRChat起動中に警告が表示され、復元などの処理は負荷を抑える設定で動作します。

### 圧縮中にアプリがハングしているようにみえる

JXL圧縮は大きなファイルほど時間がかかります（数秒～数十秒）。
処理完了まで少しお待ちください。複数ファイルは順番に処理されます。

### OSC連携を使いたい

VRChat側でOSCを有効にし、ゲーム関連設定 > 画面設定で「OSC通信を有効化」をオンにしてください。標準ポートはVSA受信 `9001`、VSA送信 `9000` です。使用するカメラ（VirtualLens2、Integral、FishEye、TelePortraitLens）のOSC出力を有効にするとカメラパラメータを取得できます。

### ワールド名やユーザー情報が表示されない

写真の情報は写真の埋め込み情報とVRChatログ、OSCから取得します。ゲーム関連設定 > 画面設定でログフォルダとOSCを確認し、VRChatのログが作成された状態で新しい写真を取り込んでください。

### アップデート方法は？

新しいバージョンがリリースされると、アプリ起動時に自動通知されます。
設定から「今すぐアップデート」をクリックするか、最新版をダウンロードして上書きインストールしてください。

- このアプリは**個人開発**のソフトウェアです（VRChat公式とは無関係）

- ローカル写真管理などの基本機能はPC内で動作します。VSAアカウント、クラウド保存、X投稿、Turnstile、アップデート確認、サーバーステータス表示を使う場合は外部通信が発生します。
- クラウド保存とX APIを利用する機能は、無料枠を超えると料金が発生する場合があります。
- ローカルファイルへのアクセスは、ユーザーが選択した監視フォルダ・書き出し先とVSAの管理領域を中心に行われます。
- 大切なデータは**定期的にバックアップ**をお願いします

- **Windowsセキュリティ**: 初回実行時にスマートスクリーンで警告が出る場合があります。「詳細情報」から実行してください
